# 3 — The stop check can be switched on with evidence behind it

## Outcome

A person can set the stop check to `on` knowing how often it is wrong, and a record says whether `on` becomes the default.

## Done means

- An ADR decides the default mode and cites the replay report (ADR-3). Evidence: the ADR.
- In `on` mode a flagged turn shows its note in a live session. Evidence: a capture of that session.
- The README states the measured false-alarm rate. Evidence: the README.
