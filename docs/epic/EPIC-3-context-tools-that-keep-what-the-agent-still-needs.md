# 3 — Context tools that keep what the agent still needs

## Goal

Long sessions cost less and lose less: tool output is cut down as it arrives, and compaction keeps chosen items word for word.

Compaction is the idea the kit started from (RFC-1). It is also the feature most likely to fail without anyone noticing, so it stays in shadow mode until our own evidence supports switching it on (ADR-3, ADR-6).
