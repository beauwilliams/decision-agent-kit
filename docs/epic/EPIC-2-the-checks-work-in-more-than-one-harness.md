# 2 — The checks work in more than one harness

## Goal

A person using Codex gets the same checks as a person using Claude Code, from one core and one ledger format.

It matters because supporting more than one harness is a stated goal of the kit (RFC-1), and the core was kept free of any one harness for this reason (ADR-2).
